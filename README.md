# idormap 🗺️

[![Python](https://img.shields.io/badge/Python-3.12-blue)](https://www.python.org/downloads/release/python-3120/) [![GitHub Repo](https://img.shields.io/badge/GitHub-idormap-black?logo=github)](https://github.com/idormapproject/idormap/) ![Version](https://img.shields.io/badge/Version-1.0.0-purple)

idormap is an open-source security testing tool designed to detect and exploit IDOR (Insecure Direct Object Reference) vulnerabilities in web applications. It helps security researchers and penetration testers identify broken access control issues caused by improper authorization of object-level references, and evaluate whether sensitive resources can be accessed or modified without permission.
